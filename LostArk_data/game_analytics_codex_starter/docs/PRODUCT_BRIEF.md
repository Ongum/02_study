# Product brief and philosophy

## Vision
A reusable entertainment-data platform where ingestion exists to support trustworthy product decisions, accountable experiments and meaningful improvements to player/user experience.

## Career outcomes
Demonstrate (1) DE: API integration, incremental loads, data contracts, reliability, IAM and cost control; (2) DA: meaningful game KPIs, domain-specific interpretation, confidence intervals and dashboards; (3) DS: anomaly detection, NLP classification and honest evaluation. Each outcome needs tangible artifacts and measured comparisons.

## Social value
Detect emerging player pain points, highlight language-specific issues without stereotyping, limit exposure of user data, reduce manual triage time and publish explainable results. No claim that these findings were adopted by Smilegate or changed its users' outcomes.

## Users and decisions
Hypothetical live-ops analyst: which patch coincides with changed reviews? Hypothetical community manager: which issue category needs review? Portfolio evaluator: can they rerun the tests, inspect data contracts and distinguish correlation from causation?

## MVP scope
Lost Ark Steam reviews + news + observed current-player snapshots, Bronze/Silver/Gold, daily negative review share, update-window comparison and baseline issue alerting. Later: multilingual NLP and additional connectors. Out of scope: proprietary game logs, revenue, retention, bot detection claims, a large-scale realtime system, simulated engagement reported as real.

## Success gates
Repeatable offline tests; permitted API smoke results; review identity dedupe; explicit gap/recovery tests; trustworthy daily marts; valid update windows; statistical uncertainty; baseline vs improved alert latency/precision measured on labeled samples; GCP cost and job traceability; clear README/demo. Targets are not achievements until run and measured.
